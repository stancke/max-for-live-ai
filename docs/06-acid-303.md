# M4L Acid 303

Instrumento com voz inspirada na TB-303 e gerador de clipes MIDI. A geração de clipes requer o arquivo `m4l-acid-clip-runtime.js` ao lado do `.amxd` e Live 12.2+ com Max 9.
Arquivo gerado: `dist/M4L Acid 303.amxd` (Instrument, `iiii`).

## O que ele faz

- Sequenciador de **16 passos** com banco de **16 patterns**.
- **Duas fontes**: `MIDI` (notas externas, ex.: PULSESEQ) ou `SEQ` (sequenciador
  interno sincronizado ao transporte/tempo do Live).
- Voz monofônica 303: oscilador **saw/square**, filtro ressonante, envelope de
  filtro, **accent** e **slide**.
- Botão **GENERATE** cria um clipe MIDI aleatório no primeiro slot vazio da propria faixa na Session View.
- Todos os controles são parâmetros do Live (automação, Push, mapeamento).

## Controles

| Controle | Faixa | Unidade | Padrão | Função |
|---|---|---|---|---|
| **Cutoff** | 80–8000 | Hz | 600 | Corte do filtro |
| **Resonance** | 0–1 | — | 0.7 | Ressonância |
| **Env Mod** | 0–100 | % | 60 | Profundidade do envelope de filtro |
| **Decay** | 30–800 | ms | 220 | Decaimento dos envelopes |
| **Accent** | 0–100 | % | 60 | Intensidade do accent |
| **Volume** | -24–+6 | dB | -6 | Saída |
| **Root Note** | 24–60 | MIDI | 36 (C1) | Nota raiz |
| **Octave** | -2–+2 | — | 0 | Transposição em oitavas |
| **Pattern** | 0–15 | — | 0 | Pattern atual |
| **Length** | 1–16 | passos | 16 | Comprimento do loop |
| **Rate** | 1/8, 1/16, 1/32 | — | 1/16 | Divisão do sequenciador |
| **Wave** | Saw, Square | — | Saw | Forma de onda |
| **Generate** | botão | — | — | Cria um clipe MIDI em um slot vazio |

| **Run** | on/off | — | on | Liga o sequenciador interno |

### Source e Run

- **SEQ**: o sequenciador interno toca os 16 passos **livremente**, sem
  precisar do play do Live. O **Run** liga/desliga o sequenciador; o play do Live
  só realinha o contador no passo 0.
- **MIDI** (padrão): notas que chegam no `midiin` disparam a voz. O PULSESEQ (ou qualquer
  sequenciador MIDI) toca o 303. Velocity > 100 vira accent; note-off é ignorado
  (o envelope decai sozinho, como no 303). Nesse modo o sequenciador interno fica
  mutado.

Ambos são parâmetros do Live, então podem ser automatizados ou mapeados.

## Patterns

O banco é gerado no build por um PRNG determinístico (`mulberry32`), com regras
musicais:

- escala pentatônica menor + b5 (`0, 3, 5, 6, 7, 10, 12`);
- densidade, acentos, slides e saltos de oitava variam por pattern;
- passo 0 sempre toca a raiz com accent;
- mínimo de 4 notas por pattern.

O pattern fica armazenado em um objeto `coll` (256 entradas: 16 patterns × 16
passos × `[note, accent, slide, gate]`), inicializado no load por mensagens
`store`.

## Fluxo do clock

```
loadbang / live.thisdevice  →  bang  →  metro do sequenciador (roda livre)
metro 20  →  plugsync~  →  tempo (outlet 5)  →  intervalo do passo
                         →  transporte (outlet 0)  →  reset do counter
```

- `metro` é iniciado com **bang** (não existe mensagem `start` no objeto metro).
- `change` detecta **transições** de transporte (evita reset a cada poll).
- O `counter 0 15` percorre os passos; o máximo é atualizado por `Length - 1`.
- `Pattern × 16 + Step` é a chave consultada no `coll`.
- O play do Live **não** para o sequenciador: ele apenas zera o contador para
  alinhar o passo 0.

Observação: a fase do sequenciador é livre; o play realinha o contador no
momento em que é detectado (≈20 ms de polling). Ele não se re-alinha ao compasso
a cada barra.

## Fluxo de um passo

```
Source = SEQ:
  coll → unpack [note, accent, slide, gate]
  gate = 1 e Run ligado → trigger

Source = MIDI:
  midiin → midiparse → unpack [pitch, velocity]
  velocity > 0 → trigger
```

Depois do trigger (qualquer fonte):

```
pitch (MIDI ou root+octave+note) → mtof → line~ (glide 0 ms ou 60 ms)
VCA:    line~ "1 2 0 decay"
filtro: line~ "1 2, 0 decay"  (só se slide = 0)
```

- **Slide**: o pitch glida 60 ms; o envelope de filtro **não** é retriggerado.
- **Accent**: aumenta o envelope de filtro (até +3000 Hz) e o VCA (até +60%).
  No modo MIDI, velocity > 100 liga o accent.
- **Rest**: gate 0; o envelope anterior continua decaindo.

A voz é monofônica: uma nova nota sempre rouba a anterior.

## Cadeia de áudio

```
saw~ / rect~ → selector~ → lores~ → *~ (VCA) → *~ (volume) → plugout~ (L/R)
                    ↑           ↑
       envelope de filtro → *~ depth → +~ cutoff
```

## Limitações desta versão

- Os patterns são fixos no build; **não há edição passo a passo** nem
  persistência de patterns editados no Set.
- Sem swing/shuffle.
- No modo MIDI, o slide não é detectado automaticamente (notas sobrepostas não
  viram glide). O accent usa velocity > 100.
- A fase do modo SEQ reinicia no play, mas não é re-alinhada a cada compasso.
- O sequenciador interno usa seu banco fixo; os controles de tom e escala se aplicam ao clipe gerado.

## Teste no Live

1. Arraste `dist/M4L Acid 303.amxd` para uma **MIDI Track**.
2. **Source = SEQ** e **Run = on**: o sequenciador interno deve soar
   imediatamente, mesmo com o transporte parado.
3. **Source = MIDI**: toque notas (ou deixe o PULSESEQ mandar MIDI) — deve soar
   sem precisar de play.
4. Ajuste Cutoff/Resonance/Env Mod/Decay para o timbre.
5. Para gerar clipe, escolha TOM, ESCALA e COMPASSOS e clique em GENERATE. Use Source = MIDI e reproduza o clipe. RATE define a divisao das notas.
6. Automatize Cutoff/Resonance e confira se aparece na automação.

Se ainda não soar, teste primeiro o `dist/M4L Tone Test.amxd` (seno contínuo de
220 Hz). Se ele soar, o problema é no Acid; se não soar, é roteamento/volume da
track.

Se o device não emitir som, confira: Source correto, track com instrumento,
volume/fader, notas chegando no `midiin` (modo MIDI) ou play ativo (modo SEQ), e
o parâmetro **Volume** acima de -24 dB.

## Geração de clipe MIDI

Mantenha `M4L Acid 303.amxd` e `m4l-acid-clip-runtime.js` juntos. Na Session View, escolha TOM, ESCALA e COMPASSOS (1, 2, 4 ou 8 compassos de 4/4) e clique GENERATE. O clipe aparece no primeiro slot vazio da propria faixa. Para ouvir com o Acid, use Source = MIDI e inicie o clipe. Slot ocupado não é substituído.

RATE escolhe 1/8, 1/16 ou 1/32; acentos usam velocity 115 e notas comuns 80. A nota base do clipe é C MIDI 36 mais o tom escolhido. OCT transpõe também o MIDI reproduzido; para a oitava original, use OCT = 0. O clipe não representa slide 303: o modo MIDI atual não interpreta sobreposição como glide. ROOT, PAT e LEN controlam o sequenciador interno, que continua usando seus patterns fixos; TOM e ESCALA aplicam-se aos clipes gerados. Caso uma falha ocorra após criar o slot, um clipe vazio pode permanecer.

Os geradores procuram de cima para baixo o primeiro slot vazio existente na faixa do dispositivo. Se todos estiverem ocupados (ou nao houver cenas), exibem um aviso; nao criam cenas nem substituem clipes.
